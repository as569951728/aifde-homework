# W01 作业批改意见

来源：学员于 2026-10-27 在 W01 实操会话粘贴的老师批改原文。未提供评分、平台回执编号或批改人姓名，以下不补写。此意见用于修订作业表达与分类，不是新增客户业务证据。

## 作业优点

判断很稳：三个月见效严格当作客户期望，没有写成承诺；对访谈导出里的状态字段也做了核查，不把平台的待审状态当成立项批准。人工复核时你发现第 7 个评估用例把 M004 写成“近两月无下单”，工具结果是对的、建议文字错了，你保留了证据并记进基线，这正是我们希望的失败归因方式。脱敏方案、采纳率怎么统计也想得很细。你如实写明了哪些是自己的回答、哪些是助手补充，这个习惯很好。

## 作业缺点

fit-gap 四行里有三行记了待判断。其中“识别重点经营会员”，产品在样例上已经验证过净消费筛选，可以先给一个初步分类，再写明青禾的规则未定；“核清复购和活跃定义”更像待核项，可以放进报告的待核清单。访谈中途问了一句公司的经营模式，沈总把话题拉了回来，材料里已有的背景可以不占访谈时间。

## 改进之处

W02 修订时，先给识别这一行一个初步分类，再用小林给的规则去验证。访谈前把材料里的背景读完，访谈时只问对方才能回答的问题。报告里写给自己的说明也可以挪出正文，读的人更容易看清你的判断。
