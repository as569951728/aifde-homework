# 初稿整理：复购改善与小林提效的材料取舍

## 1. 问题与范围
本轮只支持两个判断：复购改善方向下哪些会员需要关注；小林日常整理、核对、跟进中哪些环节值得提效。不建完整系统、不追指标数值。当前没有可引用的正式模型或运行结果；以下为回放初稿建议。据任务说明，CLM-001-0020、CLM-001-0021已有先前人工反馈，按角色诉求和权限限制保留，本次不新增确认。

## 2. 整体结构
采用“核对活动 + 数据使用边界 + 候选支持方式”的最小结构，不把Excel工作记录建成核心对象。现状可定位为：小林整理名单和执行记录，遇到对不上的信息找同事确认，反复跟进进度；核对涉及名单、执行记录、线上/门店执行安排、优惠券发放/核销记录、会员标签等信息类型（MSG-01648；CLM-001-0027）。活动输出、交接对象和状态更新规则尚不完整，暂不画成已确认工作流。

## 3. 拟采用、保留与暂缓
- 数据使用边界（拟采用，需核查）：CLM-001-0006与CLM-002-0036指向同一件事：Excel是小林手工维护的日常账，不能当全公司统一口径；一条记录对应什么、记哪些信息，需看表内实际记录，不能凭字段名推断用途（MSG-01648、MSG-01652）。理由：它直接约束助手和复购分析的数据来源，避免把个人记录误当统一事实源。拟合并为“数据使用边界与记录粒度未知”，不新增“工作记录”对象；记录字段、粒度、统计口径均标待核。
- 权限与人工确认（保留）：CLM-001-0021明确人群和执行方案需业务人员确认，未授权助手自动发券、联系会员或改记录（MSG-01637）。理由：这是候选支持方式的硬边界，影响后续流程设计和任何自动化设想。
- 候选需求（保留，非已批准能力）：CLM-001-0020希望助手先整理需要关注的会员并讲清建议依据，减少重复整理和核对（MSG-01637）。理由：它对应提效目标，但数据来源、助手范围、输出形式和确认流程未知，只能放“目标与候选方案”，不能写成已有功能或效果。
- 核对信息类别（拟作背景/待定）：CLM-001-0027说明核对会碰到名单、执行记录、线上/门店执行安排等。它可帮助界定核对活动的信息范围，但仅凭概述不足以建立独立对象或关系；建议暂不单独建对象，待实际记录和交接方式明确后再定。
- 痛点背景（暂不进入核心模型）：CLM-001-0018描述反复整理名单/执行记录、找同事确认、跟进进度，且未量化，也明确不能说成复购下降原因（MSG-01637）。可保留为提效背景和候选需求的动机，不作为现状量化基线或因果解释。

## 4. 原文反查的新线索（待补候选，不编ID）
MSG-01648还提出：优惠券发放记录和核销记录是两个环节，发放记录不能当核销记录用；具体状态和统计口径需结合实际记录核实；会员标签含义需看实际怎么填。这些是影响统计和核对规则的关键内容，但现有候选未单独覆盖。建议标为待补候选，交FDE判断是否补提；在补提和核查前，不写成已确认规则。原文speaker字段标为assistant，而候选主体记为小林/林；发言者归属与转写元数据存在标签差异，建议人工核对，但不影响上述内容取舍。

## 5. 关键未知与受阻部分
- Excel一条记录对应什么、字段含义、记录粒度未知；因此不能定义执行记录对象、字段或自动核对规则。核心模型可先保留“记录粒度未知”的边界，不依赖它展开。
- 优惠券发放/核销状态、统计口径、会员标签含义未确认，不能据此判断“需要关注会员”的筛选口径。
- 线上/门店执行安排的记录方式和交接未明，暂不补箭头式流程。
- 助手数据来源、输出范围、业务人员确认点未定，候选方案不能进入执行授权。

## 6. 本轮核查建议
拟请FDE核查：A. CLM-001-0006 + CLM-002-0036合并后的“数据使用边界与记录粒度未知”表达是否准确，是否同意不建“工作记录”对象；B. CLM-001-0027是否仅作背景、暂不单独建模；C. CLM-001-0018是否同意只作为痛点背景，不进入核心模型。CLM-001-0020、CLM-001-0021已有先前反馈，本轮不重复送审。上述是核查安排建议，未实际发起或获得新反馈。

拟做四步：1）准备将CLM-001-0006与CLM-002-0036合并成“数据使用边界与记录粒度未知”一组，提交FDE人工核查；理由是这会直接决定Excel能否作为助手和复购分析的数据来源。2）CLM-001-0027暂按背景/待定处理，CLM-001-0018暂不进入核心模型，只保留为提效痛点背景，避免为凑批次增加核查项。3）将MSG-01648中“发放记录不能当核销记录用”、优惠券状态与统计口径、会员标签填写含义列为待补候选，请FDE决定是否补提，不自行编造候选ID。4）另列后访任务：查看Excel实际记录以明确记录粒度；向业务人员确认优惠券发放/核销口径、标签填写方式、线上/门店执行安排交接，以及助手数据来源和人工确认点。本回放未调用工具、未生成正式模型、未写入文件，也未获得新的人工确认。
