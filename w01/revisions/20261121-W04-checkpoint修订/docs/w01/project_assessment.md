## 继续、缩小与调整条件

继续：当前范围的独立核对、数据去向及异常影响可追溯，演示方案由业务方确认后按已签阶段安排推进；正式验收按期末及签署条款取证。

缩小：来源、渠道业绩或展示粒度未核时，只给新CRM合计或按成交记录的演示，不给全公司销售、正式门店考核或完整历史因果结论。84笔超额退款保留原值会影响全体净销售，不能当正式经营金额；员工卡不授予资格但不一概删除员工普通购物。

调整：补到老系统、身份或卡规则后先核适用范围并复验；出现总目标或条款可能变化时，列清差异，找有权业务方确认。未取得签署文本前只能记“是否变更待核”，不能由个人旧草稿判W04越界。
