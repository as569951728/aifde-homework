# 青禾指标构建方法 v0.1

当前开发起点为一项订单金额指标；以实际 targets 为本批边界。方法可继续扩展，未运行的其他目标不代表已验证。业务事实来自输入，不从测试答案、样例客户或指标名字补事实。

## 一、目标与输入

逐项核 targets 的真实 ID 和中文名，定义或未决二选一，不新增、遗漏或改名。business_model 提供对象、关系、粒度与有源业务规则；materials 中报表及财务说明提供该指标的统计选择，字典解释字段；access_tables 确认可用物理列。注意区分通用订单指标与特定资格人群的月报指标，不能把后一种范围扩散到前一种。

## 二、候选与依据

写表达式前，为目标核齐：统计对象、一行含义、时间归属、纳入/排除条件、金额或数量组成、聚合及单位。多份资料互补则合并依据；同词异范围分别处理；真正冲突留未决，不因文档顺序而裁决。角色已说明的规则不因正式历史凭据尚缺而全部变成未知，角色说明也不升级为生产核验。

catalog.sources 使用输入真实文件名与能够支持定义的连续逐字原文；不能拼接句子、改标点、引用相邻主题代替当前断言。business_model_usage 保留实际用于对象、粒度或关系的模型原句及对应输出对象，不为凑引用声称模型中存在报表公式。

## 三、字段与计算转换

先确定事实行，再按字典逐项映射字段，不先连接所有表。金额类逐项核实计入金额、扣减金额、记录状态、统计日期、底层单位与展示换算；按材料选择对应行级表达式后聚合。排除行可按有源条件贡献零，但不能把缺字段、未定义或覆盖外解释为零。保留所需原始行和维度，不用只保留正金额行来代替材料明确的纳入条件。

同值两笔订单仍是两笔事实，不使用 sum(distinct 金额) 去重。用于判断资格的多卡关系不得放大订单金额；无关当前目标的资格判断不加入表达式。退款按材料指定的时间归属，不臆造不存在的退款时间列。物理字段精确沿用 access_tables；整数分保持原单位，不在 measure 内提前换成元。

## 四、依赖与输出

严格按输入 native_format 和 contract 返回一个 JSON 对象，仅含 semantic_models、metrics、catalog、model_sql、grain_keys、unresolved、business_model_usage。无 Markdown 围栏。每个所选目标只在 metrics 或 unresolved.metric_id 一处出现，catalog 与已定义 metrics 一一对应；measure 名称全局唯一。

simple 通过 type_params.measure 引用本次定义的 measure；ratio 的分子分母必须是本批已定义的 metric ID。依赖不闭合则留未决，不暗借历史库。catalog 填中文名、别名、单位、constraints、sources、query_policy；约束须与公式及实际业务范围一致。仅当该指标的资料要求完整月时设置 full_month_only=true，不能把其他指标的整月限制迁来。生成前逐项检查公式量纲、单位、来源和查询限制一致。

## 五、缺口与修订

区分定义缺失、真实口径冲突、字段缺失与关系缺失。无法确定的 metric_id 或 dimension_id 列入 unresolved，写 missing_facts 和具体 reason；不为通过检查编造业务规则、负责人或字段。尚未实现不等于业务资料缺失。小批次虽然只选部分指标，但完整 dimension_targets 仍须依据已知关系建模，不能把现成的账户/门店关系伪报未决。

修改方法或补充有源资料后重新生成并保留失败版本；不直接修改生成响应、YAML 或 SQL 冒充方法改善。当前无需其他目标的派生计算时不生成它们。

## 六、语义模型、角色与粒度

依据当前目标及全部维度目标建立最小完整语义图：先列事实行与唯一实体，再把已确认外键指向对应唯一目标，最后挂属性。不同业务角色分别建语义角色，即使来自同一物理表，也不能把成交门店与会员归属门店合并成同一路径；关系来源必须能追到业务模型或字典。一个实体名只能有一个 primary/unique 目标，其他出现为 foreign。避免为了展示维度把一对多明细直接连接到事实行。

每个 semantic_model 返回 name、model、entities、dimensions、measures；有统计时间时给 defaults.agg_time_dimension。model 为 ref('实际模型名')。dimensions[].name 只用局部属性名；查询 ID 的实体前缀由关系生成，不能将含双下划线的查询 ID 填入局部名。逐个核 dimension_targets 的实际可达路径；多跳只保留有依据、可唯一识别的角色路径。

每个模型用 grain_keys 声明真实列名组成的粒度；primary/unique 键须唯一且非空，foreign 指向同一业务对象，不借拼接吞掉空值。包含维度的模型必须有主实体或 primary_entity。不同粒度/行集合使用不同主实体，不重复实体—维度配对。metric_time、day、month、year 等为保留名，不能当局部实体或维度名；统计日期用真实列或非保留的派生日期列，默认统计时间与该指标归属一致。

只在必须多阶段排序、累计或判断存在时生成 model_sql，否则空对象。派生模型只用 SELECT/WITH 与 {{ ref('模型名') }}，名称不能覆盖接入表或 time_spine，不用文件/网络读取、DDL/DML。输出前核全局依赖、完整维度、主外键、实际粒度与不放大事实行；不声称编译通过就证明业务正确。
