# 首项指标的复现入口

工作目录为 W03/实操工程。本轮只构建净销售额，使用已有环境及本地钥匙串入口；不需要重新初始化。下列为本轮已采用的调用形式；再次运行须改用新的输出目录并重新锁定该库的版本，不覆盖现有证据。

```sh
.venv/bin/python -B setup/run_with_local_key.py w03 build --config customer/w03/build.json --metrics net_sales_cents --output artifacts/w03/net-sales-first-20261108/build-v3
.venv/bin/python -B setup/run_with_local_key.py w03 merge --data materials/data/small --inputs artifacts/w03/net-sales-first-20261108/build-v3 --output artifacts/w03/net-sales-first-20261108/library-v2
.venv/bin/python -B setup/run_with_local_key.py w03 load --library artifacts/w03/net-sales-first-20261108/library-v2 --data materials/data/small --project .runtime/qinghe-net-sales-small-v2
.venv/bin/python -B setup/run_with_local_key.py w03 test --project .runtime/qinghe-net-sales-small-v2 --cases artifacts/w03/net-sales-first-20261108/execution-tests-v2.json --output artifacts/w03/net-sales-first-20261108/test-v2 --judge-command .venv/bin/python customer/w03/judge.py
```

独立期望先由 `independent/calculate_expected.py` 读取原CSV算出，逐单理由在 `independent/order-ledger.csv`。`customer/w03/tests.json`保留业务期望；执行前从已加载项目的dataset.json取得数据与库版本，另存execution-tests-v2.json，仅增加版本字段，不改金额、日期、分组或状态。期望没有送给被测模型。

测试报告的comparison只判断结构、条件、数值及版本；完整解释另由独立Agent逐句审查。故意错误的判定器测试另见judge-injections-v2.json，其中null/0是合成协议对照，不冒称净销售额真实返回null。

当前产品聊天绑定未切换；本轮通过原生w03 test调用实际MetricsAgent和查询引擎，未声称网页已启用青禾库。
