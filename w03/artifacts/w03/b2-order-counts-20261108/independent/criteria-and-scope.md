# B2 独立判据、数据与区分力

期望从原日报、字典、工具契约、测试指南及原 CSV 独立形成。冻结时间和逐文件 SHA256 见 `expected-freeze.json`，冻结先于读取现有 Skill/judge，未读取生成库、执行 SQL 或实际问数结果。`calculate_expected.py` 只用 Python 标准库逐行计数，不导入被测实现；五类单行 fixture 另以明确真值向量校准。

七列顺序：创建、支付、有效、取消、退款、部分退款、全额退款。统计对象均为唯一 order_id，状态、金额条件分别判断，按 Asia/Shanghai 的 ordered_at 半开日期窗口归属，单位 count（单），不做会员资格筛选。原字典一行一单；订单号唯一性、外键、合法状态、退款非负且不超实付、取消零支付均经原 CSV 核对。订单数量不是 CRM 账户数或商品件数。

| 指标 | 独立计入条件 |
|---|---|
| 创建 | 全部唯一订单号，包括取消 |
| 支付 | status=paid，包括全退及零实付 paid |
| 有效 | paid 且 paid_cents-refund_cents>0 |
| 取消 | status=cancelled |

| 部分退款 | paid 且 0<refund_cents<paid_cents |
