## 1. 当前阶段结论

**建议继续本期合成测试范围内的业务模型更新、指标构建和独立验证，形成可追溯、可核对的问数成果。真实数据分析、会员筛选与运营执行、生产接入及上线，分别在所需条件落实后评审。当前不承诺复购提升、三个月见效或投资回报。**

继续的依据比 W01 时更具体：本期已有四张合成 CSV 和数据字典、38 项指标目标及书面定义；小林补充卡产品范围、账户资格与购买人群，陈姐补充有效期端点、提前终止空值和多卡不重复规则，王经理认可测试交付分期思路并给出核查要求。可以开始把这些规则落到模型和计算，不必因本期已有答案而重复访谈。上述来源仍需经过采用审核、字段映射和实际验证，现有工作模型仍为 W02 v0.4，不能记成已经完成 W03 交付。

本期问数工作的用途是帮助运营核对口径、数量和重复／遗漏，并为后续分析准备一致的计算基础。小林未提供节省工时或复购归因统计，测试数据也不能证明真实经营原因。沈总“先验证复购下降原因”的目标仍保留，不能用完成指标数量代替原因验证，也不能将王经理的核查意见写成发起人已经变更业务目标或公司正式批准。

## 5. 下一阶段的条件、责任和验证

### 5.1 本期可推进的工作

复用现有工程、四张测试 CSV 和正确 W03 访谈，先审核新旧模型差异，再沿既有提取与审核流程更新模型。随后生成候选指标、核定字段／粒度／时间范围／单位及限制，实际查询，并从同一版本原始数据独立确定期望。先验证关键边界，再覆盖全部 38 项、小样本与规模数据；保留失败和修正记录，同时审查回答解释。

材料中有定义、角色答复清楚、候选被采用、计算通过、客户确认和业务收益是不同状态。当前已具备本期定义来源，尚未完成正式核定或查询验收。测试发现计算／关联错误先修实现；只有暴露真实规则缺口或冲突才补访谈。

### 5.2 客户与交付方的工作

王经理 03919 说明：客户提供或确认指标清单、测试范围、统计口径、验收依据和留证方式；交付方准备查询与独立核对结果、追溯／校验说明和双方责任草案。运营核业务范围，IT 核字段与覆盖，王经理核统计口径与验收依据。该分工没有落实每项材料的具体经手人、时间或最终验收权限。

陈姐 03888／03890 要求门店配合前先明确适用范围、工作量、现场问题责任和工作记录；要求不清或影响考核先澄清。这是安排条件，不代表本期已安排门店任务，更不改变门店考核。

### 5.3 费用、变更、延期和验收权限

按王经理 03923—03933，SOW 草案应落实以下要求并保留未决：

- 费用列构成和计价依据，金额未谈妥待确认；结算对应约定成果和确认记录。具体项目、金额、节点、记录形式及付款条件未定，不预填比例或期限。
- 范围变更书面提出，写内容、费用和责任影响及是否超出支持范围。后续会员筛选的具体支持条件按任务书要求以能力交付时的书面范围确认为准；这是后续范围安排，具体条件和确认责任仍待落实。
- 若有配合延期，留缺项清单、通知时间、实际影响及受影响／不受影响工作。能否继续及怎样排期由执行安排方决定；受影响排期和费用双方书面确认后再请王经理复核。该情形尚未实际发生，不能写成自动顺延、加费或客户责任已成立。
- 依据不足或费用范围不清可暂缓财务确认；这不等于本期课程测试工作全部停止。实际项目承诺、排期或结算需要落实相应负责人和确认条件。
- 王经理只能提核查意见。03931 明确最终验收人、授权额度、具体授权材料及审批安排不掌握；不能默认由他或沈总拍板。预算、验收、签约、续约及上线确认分别保留。

依据：[王经理正式访谈](../w03/sources/interviews/W3-interview-92c91632-4b0e-5a7a-bd7d-55214f68ee39-transcript.json)。

### 5.4 后续访谈怎样使用

当前先进入模型审核和实现验证，不为消除所有未知而继续泛问。取得代表性查询和独立对照后，请小林核输出是否便于核对业务；形成实际 SOW 段落与证据摘要后，请王经理提出意见并修订。老周、陈姐仅按新发现的数据问题或具体协作事项补访。

若需要确认下一阶段经营价值与优先级，可向有相应职责的业务负责人核可支持的决策、前提与观察方式；具体是谁仍依材料落实，不能把核查岗位当授权岗位。真实生产接入、旧四季度原因分析、筛选与运营执行的未决继续保留，不扩大本期测试结论。
