## 离线验收集

- **T01 / positive** 提前终止早于计划截止，判定日在开始与提前终止之间；完整字段及两个区间正确。 预期：通过。
- **T02 / positive** 空终止且判定日为生效当天；下界包含、计划截止仍约束。 预期：通过。
- **T03 / positive** 空终止，计划结束前一天/当天/后一天；正确结论及端点。 预期：分别有效/无效/无效，均为正确答复应通过。
- **T04 / positive** 提前终止晚于计划截止；综合截止取计划截止。 预期：通过。
- **T05 / positive** 指定历史判定日与运行日不同，使用历史日。 预期：通过。
- **T06 / negative** 仿R2 DQ12：保留正确未生效结论/各条件，把综合截止错写计划截止。 预期：综合区间不符合原材料与题设，必须失败。
- **T07 / negative** 正确有效结论不变，只把综合下界改一天；或只把计划区间改错。 预期：相应区间失败，不能只看最终结论。
- **T08 / negative** 将开始端不含或结束端包含；使用端点当天fixture以暴露边界。 预期：端点标记/规则失败。
- **T09 / negative** 分别翻转每个日期条件布尔；null分支误作有终止；只检查一个失败条件而忽略其余。 预期：条件对题设不符，失败。
- **T10 / negative** 保持条件/区间正确，仅翻转最终结论，正例反转与负例反转都覆盖。 预期：结论合取/区间成员关系不符，失败。
- **T11 / negative** 把条件、综合区间与最终结论一起改成互相自洽但相对真实题设错误。 预期：独立规则核对失败，不能被内部一致性放过。
- **T12 / negative** 用运行日替换指定判定日，或更换输入卡类型/起止/终止字段后给内部自洽结果。 预期：fixture身份核对失败。
- **T13 / negative** 缺字段、布尔字符串/整数、无效日期、重复键、尾随额外对象。 预期：明确结构失败，不自动修复通过。
- **T14 / semantic_gate** 结构完全正确，解释却给错误有效窗口/错误来源/生产已核验。 预期：若检查器不覆盖自然语言，机器项可过但独立完整语义必须失败；不得报告整体通过。

重点防漏：一个模型可以把条件、区间和最终结论一起写错而保持内部自洽；必须另与原题设和独立原材料规则核对。正例的预期也不能由待测函数自己生成。
