# 青禾会员经营业务模型（W03 第三稿来源细化候选，未写入）

## 1. 业务目的与适用边界

模型服务两个分别观察的目标：理解复购变化并支持选择、验证改善措施；减少运营在日常名单与执行信息上的重复整理和核对。岗位提效不能直接证明复购改善。

沈总希望第一阶段先验证复购下降原因，并先检验“会员老化”是否主因（其个人判断）；多位角色称复购连续四个季度下降，但尚未取得原报表重算。三个月见效是客户期望，改善幅度与效果定义尚未核实（MSG-01719、01731、01733、01737、01739）。沈总定业务优先级；具体专业口径与操作由相应业务／数据角色核实（MSG-01725）。

沈总所说80万指其所说的活跃会员，老周所说120万指系统全量会员；两者定义、范围、时点与来源需分别核查，现有依据不支持相减、算活跃率或断言同口径矛盾（MSG-01719、01744）。

业务知识来源为指定青禾材料与本人角色访谈。本期可用的账户、卡、订单及两种门店关系按《数据字典》：覆盖2024-09-01（含）至2026-09-01（不含），Asia/Shanghai，日期粒度，退款为截至快照的累计额。本期字典对应干净合成测试数据，不是原始 CRM；字典中的关系不代表生产环境自然人身份已统一，也不代表历史资格可还原。

## 2. 核心对象、属性与关系

| 对象 | 当前认识与最小属性 | 来源 |
| --- | --- | --- |
| 会员账户 | 经营与统计对象。一行一份 CRM 会员账户；账户不等于跨系统自然人，也不等于自然人数。属性含注册日期、归属门店、会员等级 | 《数据字典》members；MSG-01615、01679、01742 |
| 会员卡 | 卡归账户，一个账户可对应多张卡。属性含卡产品类型、权益开始日期、计划权益结束日期、提前终止日期（可为空）、购卡实付金额。购卡实付不是商品订单收入，也不直接裁定资格 | 《数据字典》cards；MSG-03848、03854、03886 |
| 派生付费资格 | 不是永久身份、会员等级、活跃状态或购买事实。含义为：给定业务范围与判定日，账户存在一张同时满足产品范围与有效期的卡。就本期总部运营月报而言，卡产品与有效期提供资格判断依据；判定日由该项统计的要求确定 | 本期产品范围与账户资格：小林 MSG-03848、03854；卡有效期及按要求的判定日检查：陈姐 MSG-03886、03888 |
| 会员等级 | 普通、银卡、金卡，与付费资格是两回事；资料只给当前等级，当前等级不能还原过去各日的等级 | 《数据字典》members.tier；MSG-03848、03866、03870 |
| 归属门店与成交门店 | 会员归属门店描述账户归属；订单成交门店描述交易发生门店，两者是不同关系，不可互相替代 | 《数据字典》members.home_store_id 与 orders.store_id |
| 购买记录／订单 | 一行一笔订单。保留订单识别、关联账户、渠道（门店或小程序）、下单日期、支付状态、原价、实付、累计退款、原始购买件数的含义。本期材料未提供订单实际使用哪张卡的关联 | 《数据字典》orders；MSG-01752、01938 |
| 有效购买 | 已支付且实付减累计退款后大于零；取消与全额退款不计为有效购买。支付状态不等于有效购买；支付订单可以全部退款而仍不是有效购买。原始购买件数不是扣退货后的净销量 | 《订单日报说明》《财务邮件》《数据字典》 |
| 复购率 | 群体指标，定义与某期结果分开表达。定义需人群、资格纳入时点、期间、分子分母、有效购买条件与渠道；结果需定义版本、来源与覆盖 | MSG-01619、01754、01766；《会员运营周报》 |
| 活跃 | 按业务规则、期间与范围判断的会员分析属性，定义未知；不是第三类会员身份，未知不判为不活跃 | MSG-01719、01754 |
| 优惠与券 | 优惠是购买相关信息，券是可能载体。发放、核销、购买、复购改善是不同事实 | MSG-01648、01752；MSG-03860、03862 |
| 反馈 | 现场问题与执行反馈是经营输入，保留事项、来源与时间 | MSG-01665、01945、01953 |

关系与边界：
- 本期字典给出：账户—卡为一对多，账户—订单为一对多，卡与订单均关联账户。本期材料不提供订单与具体卡的对应，不据卡数复制订单，也不据订单反推卡。
- 不建立“免费注册会员”与“付费卡持有人”互斥分类；账户可能同时具备多种形态（MSG-01615、01679、01742）。两类会员在系统上是否重叠尚未取得记录核验。
- 尚未取得依据的业务未知是：优惠／活动追踪与订单、反馈之间的实际关联，以及生产历史中的对应关系；其字段、一对多关系与重复计数风险均待具体分析确认。

## 3. 可复用的业务规则

1. **本期月报的纳入产品范围**：只纳入悦享年卡与家庭季卡持有人。异业联名卡即使收费也由合作方经营，不属本期自营会员范围；体验卡不纳入。该口径只约束本期总部运营月报，不改其他报表（小林 MSG-03848、03854）。正式规则文件尚未取得。
2. **资格判定方式**：账户只要有一张符合本期范围且在判定日有效的卡即具有付费资格；账户其他失效卡或不纳入范围的卡不影响该判断。必须由同一张卡同时满足产品范围与有效期，不能把不同卡的条件拼接判断（MSG-03848、03854、03870；MSG-03886、03888）。会员等级与购卡实付金额不得代替卡类型与有效状态（MSG-03848、03866）。
3. **权益有效期端点**：限于本期已说明的悦享年卡与家庭季卡——权益在生效日期当天起有效；计划权益结束日期当天已无效；存在提前终止日期时，从提前终止当天起无效。提前终止为空仅表示该记录没有提前终止，仍受计划结束日期限制，不等于无限期。资格按所需判定日期检查，不能只看当前状态（陈姐 MSG-03886、03890、03888）；各报表的判定日与统计窗口按对应指标口径确定，见核查记录。
4. **去重**：多张有效卡不重复计账户，也不重复累计订单（MSG-03848；MSG-03886、03888、03890）。
5. **统计口径要求**：人数或金额统计需明确会员范围、期间、渠道、有效购买条件与来源；标签字段含义应结合实际填写核实（MSG-01742、01754）。统计人群、待业务审核的候选人群与实际执行名单三者不可等同。
6. **优惠与措施取证**：券发放、核销、购买、复购改善分别取证；发放对象不自动等于允许使用对象；权益说明、未购回访等非券措施按各自动作与响应记录核查（MSG-01623、01648、01752、01917）。
7. **人群与执行确认**：人群和执行方案由业务人员确认；候选条件不是小林一人能定，需相应负责人确认（MSG-03856、03862）。助手不得自动发券、联系会员或改记录（MSG-03860）。
8. **门店承接条件**：门店配合前需先说明活动适用范围、具体工作量、现场问题由谁处理、门店工作如何记录；要求不清或影响门店考核的先澄清再安排（MSG-03886、03888）。

## 4. 实际工作与决策条件

小林日常经手三类工作：会员优惠券活动、会员权益说明、对一段时间未购买会员的回访（MSG-03860）。其中优惠券活动的一般做法见下表第二行，不用它代表其他两类工作。

| 环节 | 输入／触发 | 参与者动作 | 输出与交接 | 条件与未知 |
| --- | --- | --- | --- | --- |
| 运营准备与协调 | 未完任务及已有反馈（MSG-01913、01917、01927） | 小林明确面向谁、做什么，协调线上与门店安排，过程中记录进度与问题 | 整理出的名单与执行信息；找相关同事确认线上或门店的执行安排，再按记录跟进进度（MSG-03858） | 线上实际经手岗位、具体业务确认人、名单数据来源、筛选规则与完成标准均未明确 |
| 优惠券活动（一般做法） | 明确面向哪些会员、准备做什么（MSG-03862） | 确认执行方式与协作人；跟进发放与使用反馈；整理结果与尚未核实的问题 | 活动执行记录与结果、待核问题 | 具体活动、候选名单与筛选条件小林不能确认，须查实际记录并由相应负责人确认（MSG-03862） |
| 门店承接与执行 | 运营侧执行安排与范围信息 | 陈姐核对会员范围、参与门店、具体任务，向门店说明并确认人员与执行安排（MSG-01665、01949） | 执行中收问题与反馈，结束后整理情况，与小林对接 | 门店配合前需先说明范围、工作量、现场问题处理与记录方式；要求不清或影响考核先澄清（MSG-03886、03888）。完成标准待核 |
| 反馈整理与后续 | 执行中的现场问题与结果 | 陈姐向小林对接现场反馈；小林收集整理反馈（MSG-01641、01665、01945、01953） | 现场反馈由陈姐对接小林；后续分析接收者、答复返回门店的方式及进入下一轮决策的衔接仍待核 | 完整闭环未验证 |
| 数据与口径协作 | 具体对象、范围与用途说明 | 小林说明运营用途；老周核对系统统计所用的范围、时间与统计说明；运营与业务规则负责人确认口径，IT 配合字段与数据覆盖（MSG-01923、01929、01938、01942） | 统计说明与待确认事项 | 统一业务口径确认人和分析牵头人仍待核；生产或历史的字段填写及系统取值需对应凭据核验 |
| 业务决策与责任 | 阶段范围、口径与考核问题 | 沈总定业务优先级（MSG-01725）；导购有会员注册指标（MSG-01685）；王经理将注册考核核查转小林，小林表示不能确认（MSG-01824、01907） | 阶段判断与推进安排 | 门店考核的完整构成与口径、及其与活动的关系未知；最终规则责任仍待核 |

小林的岗位偏好与期望用途（不是公司优先级，也不是已实现效果）：她更希望先支持优惠券活动，想减少整理名单与执行记录、找同事核对不一致信息、反复跟进进度；个人负担未量化，也不能据此确认复购下滑原因（MSG-03856、03860）。她希望看到关注哪些会员及每条建议的依据，以减少原有整理核对（MSG-01925）；并希望取得查数答案后核对哪些账户该进、哪些漏了或重复（MSG-03866、03870）——这些是期望用途，不是已获得的营销名单或实际结果。

陈姐提出的门店侧业务观察条件：开始时是否讲清、执行中是否减少来回确认、结束后相同问题是否减少（MSG-01951、01953）。尚未用实际活动试验，不能称已经见效。
