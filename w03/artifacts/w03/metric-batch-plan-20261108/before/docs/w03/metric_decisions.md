# 指标核定与未决项

## 首项：净销售额 net_sales_cents（2026-11-08）

范围：本周青禾合成测试库；本轮只开发这1项，未代表其余37项已完成。以下为导师依据既有材料做的字段映射及核定，不登记本人独立作答或客户新增确认。

| 核定项 | 内容与依据 |
| --- | --- |
| 业务定义 | `01_订单日报说明.md`“净销售额”：paid订单实付减退款后合计；取消单不计；按原订单下单日期归属；单位分 |
| 统计对象与粒度 | 字典orders一行一笔订单，`order_id`唯一；先逐单算贡献，再按窗口/分组求和。不得连接多张卡后重复累计订单 |
| 字段映射 | `status`判纳入；`paid_cents`减`refund_cents`；`ordered_at`确定统计日期。定义对应SUM(CASE WHEN status='paid' THEN paid_cents-refund_cents ELSE 0 END)；这行是导师根据材料的映射，不是假引文 |
| 日期、单位 | Asia/Shanghai本地日期，查询窗口左闭右开；金额保持整数分，解释展示元时再除100；退款是截至快照的累计额，不另按退款发生日拆账 |
| 范围区别 | 本项为通用净销售额，不附加月末付费资格，不套用六项付费月报的整月/全渠道限制；`monthly_paid_sales_cents`为另一项目标 |
| 门店与其他维度 | 成交门店用订单的`store_id`；会员归属门店沿订单账户→members.home_store_id。不得混用两种角色。完整12维度的结构支持与已实际测试的维度分开登记 |
| 零与未知 | 覆盖内空窗的单行加总可为0；缺期间须澄清、覆盖外不支持；不是把未知和错误返回0 |
| 当前依据缺口 | 本指标定义/字段无阻断缺口；本期合成样本不能证明生产数据质量和业务效果 |
