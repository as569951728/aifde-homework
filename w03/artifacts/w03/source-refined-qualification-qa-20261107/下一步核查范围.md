# 下一小步：把业务资格规则用于月报问题

这是后续安排，尚未运行R01—R07，不计为新的通过记录。

## 为什么做

账户具有资格与账户进入某月的付费购买人数，是两层判断。下一组核查模型能否结合原始报表材料，正确使用月末资格、当月有效购买和完整月份等条件；同时区分一般月内复购与付费会员月报。

| 原用例 | 要检查的差别 | 追加材料（原题已规定） |
| --- | --- | --- |
| R01 / R02 | 月末才生效但此前购买；月末恰好到期但此前购买 | 04统计邮件 |
| R03 | 有资格但只有全额退款订单，或完全没有订单 | 01订单日报、04统计邮件 |
| R04 / R06 | 非完整月、按门店/渠道拆分、多月请求的支持边界 | 04统计邮件 |
| R05 / R07 | 月内购买与复购人数、跨月人数不能直接去重相加、当前分母 | 03会员周报 |

## 怎样检查与留证

沿用有效测试集原问题及预期。为这组准备独立批次，冻结当前候选和指定材料，先核实际请求确实包含对应原文且不含预期。现有17题运行器只支持仅模型输入，不能直接把这7题塞进去或省掉材料。

独立审核先从原材料形成逐题判据，再审实际输出；保留每题原答、来源、统计范围、推导与判读。此组只验证模型结合材料的应用，不替代38项真实查询和数值校验。

DQ10及P09原答缺陷继续保留；导师核对稿分开记，不原样重抽样或追记原答通过。若后续发现新的正文规则错误，再按影响范围修改并回归；当前不为这两处生成答复错误追加业务规则。

已有材料能解决的核对由Agent完成。只有来源冲突、缺失事实或真正需要选择业务范围的事项汇总交本人；本人学习取舍与客户正式确认继续分开。
