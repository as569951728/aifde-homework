# 月度查询支持边界：指标测试计划补充

2026-11-06。仅补充计划，未运行；原85例模型题与原v2指标计划冻结保留。当前计划应连同本补充使用。

业务材料03对普通月内三项明确整月、全门店，没有独立规定全渠道；材料04对付费六项明确全渠道全门店。这两种业务依据须分别保留。

当前工程查询契约要求月度定义设置full_month_only。引擎静态代码在任一指标启用该策略时，拒绝所有filter和除metric_time__month之外的分组；单月可以无分组，多月必须按月。即使只筛等级或会员也不能通过；混合查询包含这类指标也受限制。技术限制不能升级为客户永远不允许相应分析。

因此，9项月度指标后续测试须补：渠道筛选、等级分组、其他filter拒绝；多月未按月拒绝；单月无过滤与多月按月的正确对照；混合请求门禁和部分月拒绝。8个查询行为计划及前提见metric_plan_addendum.json。真实数值仍独立计算，当前没有结果。
