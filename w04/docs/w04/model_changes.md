## 证据依据、来源与关联指标的一致性

会员注册计数只按registered_at，未因未激活而额外剔除；资格SQL仅纳入悦享年卡、家庭季卡，员工内购卡不会单独授予资格；同账户多张卡用exists去重。月度购买仅计paid且净额大于零，超额退款负净额不进入有效购买/月度复购，全体净销售则保留负值。以上为代码事实，须与仍待核的业务映射分开；38项能执行不等于所有业务口径获确认。对应metric_changes.md与data_diagnosis.md，实际复验见artifacts/w04/revision_validation.json。
